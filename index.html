🗞️ ➜ 🤖 ➜ 📊

관심 주제(예: 의료 AI)에 대한 뉴스를 인터넷에서 잔뜩 모은 뒤, AI가 한 건씩 읽어보고 정말 관련 있는 기사만 골라내고, 핵심 키워드와 의미(숫자 벡터)까지 정리해 주는 자동 분석 도구입니다.

🧑‍🏫 비유하자면… 아주 부지런한 신문 스크랩 도우미예요. "의료 AI 기사만 모아줘"라고 부탁하면 → 수백 개 기사를 직접 읽고 → 관련 있는 것만 오려서 → 중요한 단어에 형광펜을 칠하고 → 비슷한 기사끼리 묶어 표로 만들어 줍니다.

마지막에는 "AI가 잘 골랐는지 사람이 채점하는 평가 페이지"까지 자동으로 만들어 줘서, 학생·연구자들이 결과의 신뢰도를 직접 검증할 수 있습니다.

💚 실행 환경은 Google Colab입니다. 인터넷 브라우저만 있으면 되고, 내 컴퓨터에 아무것도 설치하지 않아요.

시작하기 전 준비물딱 세 가지면 충분해요

  • 구글 계정 — 구글에 로그인되어 있어야 Colab을 쓸 수 있어요.
  • 인터넷 브라우저 — 크롬을 권장합니다. 설치할 프로그램은 없습니다.
  • 비밀번호(API 키)와 접속 정보 — AI·데이터베이스에 접속하려면 열쇠와 주소가 필요해요.
    담당 선생님/관리자에게 받은 값(OPENAI_API_KEY·DB_HOST 등)을 준비하세요. 모두 환경변수(🔑 보안 비밀)에 넣고 코드엔 적지 않습니다. (등록 방법은 ②단계)
🔑 비밀번호(API 키)가 없으면 AI 호출 단계에서 멈춥니다. 강의 실습이라면 보통 선생님이 미리 나눠 줍니다.

2

비밀번호(API 키) 등록하기처음 한 번만 하면 됩니다

🔑 ➜ 🔒 ➜ ♻️

Colab 왼쪽 끝의 열쇠 모양 아이콘 🔑(보안 비밀)을 누르면 비밀번호를 안전하게 보관하는 창이 열립니다. 비밀값·접속 정보는 코드에 적지 않고 모두 여기(환경변수)에 등록합니다. (한 번 넣으면 다음부터 자동으로 불러옵니다.)

① 비밀 열쇠 — 관리자에게 받은 값

OPENAI_API_KEYGPT 같은 AI를 부르는 열쇠 MIDDLETON_API_KEY무료 자체 호스팅 AI를 부르는 열쇠 DB_PASSWORD결과를 저장하는 데이터베이스 비밀번호 SSH_PASSWORD평가 페이지 배포용 (비우면 DB_PASSWORD 재사용)

② 접속 정보 — 어디에 연결할지 (역시 관리자에게 받기)

DB_HOST데이터베이스 서버 주소 DB_USER데이터베이스 사용자 이름 DB_NAME데이터베이스 이름 MIDDLETON_URL자체 호스팅 AI 서버 주소

평가 배포(7단계)까지 쓸 때만: SSH_HOST·SSH_PORT·SSH_USER는 비워 두면 DB 값을 그대로 재사용합니다.

  • 각 항목의 이름은 위와 정확히 똑같이, 값에는 받은 열쇠를 붙여넣기.
  • 오른쪽 "노트북 액세스" 스위치를 켜기(파란색) — 안 켜면 노트북이 못 읽어요.
🙈 비밀번호는 화면이나 코드에 그대로 적지 마세요. 반드시 이 🔑 보안 비밀 칸에만 넣습니다.
3

셀 [1.1] 하나만 고치기여기 값만 바꾸면 분석 주제가 바뀝니다

프로그램에서 직접 손대는 곳은 사실상 이 셀 하나뿐입니다. 나머지는 그냥 실행만 하면 돼요.

SEARCH_KEYWORD검색어. 예) 의료 AI — 띄어쓴 형태로 적으면 변형까지 폭넓게 잡혀요. START_DATE / END_DATE분석 기간(YYYY-MM-DD). 처음엔 며칠로 짧게 시험해 보세요. TOPIC_CODE저장 폴더 이름표. 새 주제로 처음부터 모으려면 새 값으로 바꾸기. CHAT_MODEL기사를 읽고 판단하는 AI. 처음엔 무료 gemma4, 품질이 필요하면 gpt-4o-mini. EMBED_MODEL의미를 숫자로 바꾸는 AI(임베딩). PACK_SIZE / N_PACKS평가 문항을 몇 개씩 × 몇 세트로 나눌지. (강의 실습: 20 × 5)
🧪 처음 한 번은 "짧게 시험 운전"을 추천해요. 기간을 2~3일로 좁혀 한 바퀴 돌려 정상 동작을 확인한 뒤, 기간을 1~2년으로 늘리세요.
4

위에서 아래로, 셀을 하나씩 실행▶️ 버튼만 차례대로

▶️ ▶️ ▶️ … ✅

각 코드 블록(셀) 왼쪽의 ▶️ 실행 버튼을 누르거나 Shift + Enter를 누르면 그 셀이 실행됩니다. 맨 위 [1.1]부터 순서대로 아래로 내려가며 실행하세요.

  • 셀이 끝나면 초록 체크가 뜹니다. 그다음 셀로 내려가세요.
  • [2.3]에서 AI가 한 번 인사(ping)하면 열쇠가 잘 등록된 것입니다.
  • [3.5]부터 실제 수집이 시작돼요. 양이 많으면 시간이 걸리니 진행 막대를 기다리세요.
  • [6.2]에서 예쁜 차트 3개(월별·언론사·키워드)를 볼 수 있어요.
⏳ 기간을 길게 잡으면 수집·분석에 수십 분~수 시간이 걸릴 수 있어요. 중간에 멈춰도 괜찮습니다 — 이미 모은 데이터는 저장돼 있어서, 다시 실행하면 빠진 부분만 이어서 채웁니다.
5

평가 페이지 만들고 공유하기사람이 AI를 채점하는 단계

🧑‍🤝‍🧑 ➜ 🔗 ➜ 📝

마지막 7단계([7.1]~[7.7])를 실행하면, AI가 골라낸 결과를 사람이 점검하는 평가용 웹페이지가 자동으로 만들어지고 인터넷에 배포됩니다. 마지막 셀이 평가 URL을 알려 줘요.

  • 그 URL을 학생/연구자에게 공유합니다.
  • 참여자는 학번을 입력하고, 필터·키워드·임베딩 결과가 적절한지 채점합니다.
  • 채점 결과는 자동으로 데이터베이스에 저장되어, 노트북에서 다시 모아 분석할 수 있어요.
👥 같은 문항을 두 사람 이상이 채점하면 평가자 간 신뢰도(IRR)까지 계산할 수 있어, 결과가 훨씬 믿음직해집니다.

FAQ

자주 묻는 질문막혔을 때 여기부터 보세요

"환경변수 누락" 이라는 빨간 글씨가 떠요.

비밀번호(API 키)가 아직 등록되지 않았다는 뜻입니다. ②단계로 돌아가 🔑 보안 비밀에 4개의 열쇠를 넣고, 각 항목의 "노트북 액세스" 스위치를 켠 뒤, 런타임 ▸ 세션 다시 시작을 하고 위에서부터 다시 실행하세요.

실행이 너무 오래 걸려요 / 멈춘 것 같아요.

기간이 길면 정상적으로 오래 걸립니다. 진행 막대가 조금씩이라도 움직이면 동작 중이에요. 급하면 셀 [1.1]에서 기간을 짧게 줄여 시험해 보세요. 중간에 멈춰도 데이터는 보존됩니다.

네이버에서 자꾸 차단되는 것 같아요.

프로그램에 자동 재시도·휴식 기능(안티봇)이 들어 있어 대부분 스스로 회복합니다. 그래도 계속되면 잠시 뒤 셀 [3.5]를 다시 실행하세요. 이미 모은 부분은 건너뛰고 이어서 진행합니다.

관련 기사가 너무 적게 잡혀요.

검색어가 너무 좁거나, AI 모델이 보수적으로 판정했을 수 있어요. SEARCH_KEYWORD를 조금 더 넓게(띄어쓰기 형태로) 바꾸거나, CHAT_MODEL을 gpt-4o-mini처럼 한국어 이해가 좋은 모델로 바꿔 보세요.

비용이 드나요?

gemma4 + bge-m3 조합은 무료입니다. gpt- 계열 모델을 쓰면 사용량만큼 OpenAI 요금이 발생할 수 있어요. 처음엔 무료 모델로 시험하고, 품질이 필요할 때만 유료 모델로 바꾸는 것을 권장합니다.

실수로 데이터를 지울까 봐 걱정돼요.

데이터 삭제는 오직 RESET_DATA = True일 때 셀 [1.6]에서만 일어납니다. 다른 셀은 "추가"하거나 "갱신"만 하므로, 평소엔 마음 놓고 실행해도 됩니다.
